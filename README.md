# Schedule Assistant

一个通过对话帮你梳理事务、安排日程并持续调整的个人计划 Skill，附带本地日程与任务关系界面。

你有没有过这种感觉：明明在做眼前的事，脑子里却还挂着其他事。怕漏了什么，纠结先做哪个，好不容易排好计划，临时一有变化，又得从头捋一遍。

Schedule Assistant 就是想帮你少操这份心。把手头的事情告诉它，不用事先整理清楚，它会和你一起理出头绪，拆出下一步，把各件事的时间协调好。进度有变化，再告诉它，由它接着调整。你可以专心做眼前的事，不必一直在脑中维护整份计划。

## 功能

- **梳理目标与任务**：从目标拆出行动，也能从零散事项归纳目标，通过逐步追问补齐关键信息。
- **统筹并行事务**：把工作、生活、循环事务和习惯放在同一份计划中，协调时间与推进顺序。
- **安排当周日程**：结合可用时间、截止日期、任务依赖和剩余工作量，安排具体执行时段。
- **根据变化调整**：吸收进度反馈和临时安排，重排受影响的日程；时间不足时说明冲突并提出取舍方案。
- **查看整体计划**：通过日程视图和任务关系视图，查看时间安排、目标结构与进展。

## 安装

### 运行环境

- AI 助手需要能加载 Skill、读写本地文件并执行脚本；本项目目前使用 Codex 验证。
- Python：现有 67 项脚本测试已在 Python 3.9.6 下通过；运行环境需能通过 `zoneinfo` 读取计划所用时区。
- Node.js：当前锁定的 Vite 要求 `^20.19.0 || >=22.12.0`；其 Rollup 依赖要求 npm 8 或更高版本。界面构建已在 Node.js 24.16.0 下通过。
- 系统：目前在 macOS 验证。脚本依赖 Unix 接口 `fcntl` 等，不支持原生 Windows Python；Linux 和 WSL 尚未验证。

### 获取项目

```sh
git clone https://github.com/pullllllll/schedule-assistant-skill.git
cd schedule-assistant-skill
npm --prefix app ci
```

在 AI 助手中打开克隆后的仓库目录作为工作区，并让助手加载 [SKILL.md](.agents/skills/schedule-assistant/SKILL.md)。

请保留整个仓库，Skill 会使用其中的脚本和配套界面。只复制 Skill 子目录无法获得完整体验。

## 使用

加载 Skill 后，直接用自然语言开始：

> 帮我梳理近期工作和生活中的事情，并安排本周计划。

首次使用时，助手会逐步了解你的主要事务、作息、已有安排和时区。你不需要一次说完；它会先整理已有信息，再追问影响计划的关键细节，与你确认后建立计划。

之后继续在对话中新增事项、汇报进度或说明时间变化。助手会读取已保存的计划，更新任务与日程，并在需要时打开配套界面。

## 工作方式

**理解事务 → 整理结构 → 安排日程 → 根据反馈调整**

排期前，助手先理清每件事要达到什么结果、需要哪些行动，以及行动之间的关系，再结合时间条件安排执行。

由助手推导的整体任务结构，以及改变截止日期、任务去留等重大取舍，会先与你确认。在现有约束和授权范围内的调整，由助手完成后说明结果。

计划保存前会经过脚本校验，检查数据、引用关系和日程约束；校验或提交失败时，原计划保持不变。如果现有时间无法满足全部要求，助手会指出冲突并提出调整方案，由你决定需要改变哪些承诺。

## 数据与限制

个人计划保存在 `data/plan.json`，首次使用时生成，默认不会提交到 Git。更新项目时请保留 `data/`；备份时可以复制该目录。

配套界面只读，任务和日程通过与助手对话修改。计划文件保存在本地，AI 对内容的处理遵循你所使用助手的服务和设置。

当前版本需要你主动提供事务、进度和现实变化，尚未接入外部日历、邮件或消息服务，也不提供独立的后台提醒。
